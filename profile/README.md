# Zalveriq

Zalveriq is a Git-based hosting platform for deploying any type of application.

It supports web apps, APIs, backend services, static sites, VPS workloads, game servers, and custom runtimes using Docker or native execution.

## Features

- Git-based deployment for all application types
- Framework-agnostic runtime support
- Automatic build and deployment pipeline
- Environment variable management
- Support for containers, binaries, and system services

## Supported Workloads

- Any frontend (React, Vue, Angular, etc.)
- Any backend (Node.js, Python, PHP, Go, Java, .NET, Rust, Ruby, etc.)
- Static websites
- Docker-based applications
- VPS-based services
- Game servers (Minecraft, ARK, etc.)
